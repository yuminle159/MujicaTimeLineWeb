# 节目档案

入口位于首页 Upcoming 旁，页面路径为 `programs/index.html`。

只维护 `data.xlsx` 的 `programs` 一张表：A:L 一期一行，N:Q 为独立出演者字典，与左侧同一行节目无关联。新增人员可追加到 N:Q；出演者与切片链接均用 `|` 分隔。切片填写完整的 http/https 链接，每个链接显示一个切片入口；无需为网页设置单元格颜色。

- `program_id` 保持稳定；`program` 是系列，`episode` 是官方期数，特别节目期数可空。
- `date` 为播出日期，`time` 为已确认的时刻，有时间时填写 `timezone`（如 `+09:00`）。缺失时间留空。
- `cast_name` 为标准名，`band` 为所属乐队，`band_color` 为十六进制颜色（如 `#881144`），`aliases` 为日文名等别名，多值用 `|` 分隔。
- 页面每次打开默认勾选「只看 Ave Mujica」，条件为至少一位出演者的字典乐队包含 `Ave Mujica`。取消可看全档案；未配置归属的出演者显示「其他」。出演者筛选按 N:Q 对应表顺序排列，「其他」人员放在最后，不凭姓名推断归属。
- 支持节目、年份、出演者多选、关键字和日期排序。出演者必须全部出演（A&B）；出演者控件与年份、排序并排，支持清空选择，重置恢复默认「只看 Ave Mujica」。点击节目中的姓名标签可切换该人的选中状态。出演记录侧栏暂不展示；别名归一。桌面端每行四个节目，窄屏自适应为两列或一列。
- 官方视频与切片均新窗口打开。无切片时显示「暂无切片」。

维护后在数据更新 exe 中勾选「节目档案（Programs）」生成，或运行 `python generate_all.py --programs`。完整生成也会包含此模块。封面补齐使用 `python sync_programs.py`；调用 `update-programs` skill 可核对官方节目资料，切片始终手动维护。构建发布目录使用现有 `python build_site.py`。

## Program Statistics

节目列表上方提供轻量文字入口，打开全屏分析浮层。固定统计全部已收录节目，不受列表筛选影响，不提供统计范围选择。以节目 ID 去重，未来日期的预告暂不计入；日期未知的记录参与次数统计，不进入趋势。统计范围内最早／最近出演不代表职业生涯首播或最后一次出演。

- 出演次数：个人、乐队总体两个模式。个人一期只算一次；乐队只要任意成员出演即算一期，不累加同台成员人数。
- 出演趋势：全部乐队同图平滑曲线（经过实际数据点，不超出相邻计数范围），按月或年展示，保留对应表乐队顺序和代表色；空月份为零。点击曲线或图例只看该乐队，点击空白处恢复全部；悬停突出对应乐队，点击数据点可看节目，透明点击区域半径为 14px，位于全部曲线之上以避免被其他线遮挡。横向滚动条沿用 Live Statistics 的细红色样式。
- 共同出演：Mujica 五人内部矩阵（对角线为 —，不计入色阶；其余格子按不同出演者间共同出演次数归一深浅）、五人与其他出演者矩阵（可按对方乐队缩小范围），以及 Mujica 与其他乐队的共同出演期数。两人共同出演要求同一期同时出现；乐队共同出演要求双方各至少一名成员。
- 个人档案：只包含佐佐木李子、渡濑结月、冈田梦以、米泽茜、高尾奏音，展示范围内期数、最早／最近日期、同台最多的五位，以及完整出演期目。

图表条目与矩阵数字可展开对应节目及官方视频链接。按 Escape 或右上角关闭可恢复列表和焦点。统计从现有生成数据实时计算，无需增加 Excel 字段。
