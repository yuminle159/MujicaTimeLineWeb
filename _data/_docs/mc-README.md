# MC 内容编写指南

MC 内容使用 Markdown 文件编写，放在 `live/mc/` 目录下。

## 关联方式

在 `data.xlsx` 的 **setlist** sheet 中，为需要弹窗的曲目行填写 `mc_file` 列：

| mc_file |
|---------|
| mc/0_0.md |
| mc/interview.md |

- 路径为相对于 `live/` 目录的 md 文件路径
- 任意曲目（无论 `track_title` 是什么）都可以关联 MC 弹窗
- 留空 = 不弹窗

## 语法参考

### 基本格式

| 效果 | 写法 |
|------|------|
| 粗体（红色） | `**粗体文字**` |
| 斜体（灰色） | `*斜体文字*` |
| 列表项 | `- 列表项` |
| 段落 | 空一行分隔 |

### 中日双栏对照

用 `---` 分隔日文和中文部分，渲染时自动左右分栏显示。

```
**ホントウノワタシ -再生-**
*"真正的我"*

舞台暗転。5人のシルエットが浮かび上がる。

Doloris:
「私は…私を見つけるために、ここに来た。」

---

**灯光渐暗，五人的剪影浮现。**

Doloris：
「我……是为了找到真正的自己，才来到这里的。」
```

### 5 种自定义颜色

| 颜色 | 色值 | 写法 |
|------|------|------|
| 金色 | #BB9955 | `[c1]金色文字[/c1]` |
| 绿色 | #779977 | `[c2]绿色文字[/c2]` |
| 深蓝 | #335566 | `[c3]深蓝文字[/c3]` |
| 紫红 | #AA4477 | `[c4]紫红文字[/c4]` |
| 浅蓝 | #7799CC | `[c5]浅蓝文字[/c5]` |

用法示例：
```
Doloris: [c1]「私は…私を見つけるために」[/c1]
Mortis: [c4]「仮面の下に隠した、本当の自分を」[/c4]
```

## 工作流程

1. 在 `live/mc/` 下创建 `.md` 文件
2. 用 Markdown 语法编写 MC 内容
3. 运行 `python generate_data.py`（或 `一键更新数据.bat` / `wijipedia数据更新.exe`）
4. 内容自动注入 `data.js`，在网页上点击 Interlude 行即可查看
