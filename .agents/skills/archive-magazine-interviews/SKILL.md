# 杂志访谈扫描件收录

完整收录的交付物是 `_data/mc/<最终文件名>.md`、`images/` 下的页图和工作簿访谈条目。默认翻译标题，正文留给用户翻译。用户仅要求识别、局部复核、补图或排版时，以该范围为准。编辑已有稿时保留人工译文、已确认文字和用户的重命名。

## 读取与识别

1. 先完整阅读[图片文本识别规则](../../../_data/_docs/图片文本识别规则.md)，并查看[杂志访谈成稿示例](../../../_data/mc/202601soundrecording梦结访谈.md)及同类档案。规则管原文保真；本站成稿的占位、删减和图片位置按下文处理。
2. 为每个来源页记下输入文件或 PDF 页序、封面或内页、文字区、首尾段落、与下页的接续。纸面页码可用于定位。先建立这份对应关系，再转录和插图；无需额外交付清单。
   - **PDF**：检查页面布局。可直接提取完整页面扫描图时用原始像素；含多个图层、文字叠加或裁切变换时，以完整渲染页核对版面。每个来源页制作一张发布图，保留跨页构图。
   - **图片或扫图目录**：直接看原图，无需先合成 PDF。按用户给出的顺序；目录内连续编号按自然数排序（2 在 10 前），用可见页码和正文接续核对。整页加局部放大图只对应一个印刷位置，局部用于辨字。不同位置实际重复印刷的引言要保留。无封面时只整理收到的内页。
3. 使用 Astra 目视转录。需要委派时，向可用的 Astra 代理提供原文件、识别规则和页序。先看整页区分横竖排、分栏、侧栏，再裁切原始清晰度局部核字；发布用的缩小图留到识别后制作。按自然段接续，保留问答轮次、说话人、专名、标点和停顿。逐页回看栏首栏尾，跨页整句接完整。仍不确定时按规则使用唯一的 `⟦疑1⟧` 等标记，在回复中列明页、区域、可辨部分；无疑点写“本次未标出疑点”。缺页或顺序未明时说明具体位置。
4. 在刊登稿保留标题、署名、人物简介、导语、正文、引言、相关图说及与访谈有关的唱片资料。清掉印刷页码、固定页眉页脚、无关封面宣传和照片上偶然入镜的商标。用户要求逐字全录时遵从其指定范围。

## 待翻译 Markdown

- 用最终文件名保存。文首按同类访谈列受访者、出处和已核实的信息。标题译成中文；每个 `##`、`###` 译题后紧跟单独的原刊标题块，中间不放 `（中文）`。原刊英文标题也保留原字。
- 每段待译内容的 `[original]` 上方单独放一行全角 `（中文）`。一个原文块可以含多组连续问答。提问、回答和说话人均为纯文本，段落用普通空行。原文块内不用加粗、斜体、颜色标记或 `[br]`。
- 内页图放在该页对应的最后一个完整原文块**下方**，紧随 `[/original]`，在下一节之前。遇跨页问答，在完整问答边界放图；必要时在问答之间分原文块，使图与对应的内容相邻。每张图上下各有独立一行 `[br]`。封面单独在全文最后写 `本杂志的封面：`，空行后依次放 `[br]`、封面图、`[br]`。

```markdown
### 想和 AVER 一起在舞台上唱歌

[original]

AVERと一緒にステージで歌いたい

[/original]

（中文）

[original]

――日文提问

佐々木　日文回答

――下一问

佐々木　日文回答

[/original]

[br]

![对应访谈内页](../images/文件名-02.webp)

[br]

本杂志的封面：

[br]

![杂志封面](../images/文件名-01.webp)

[br]
```

## 图片与工作簿

- 从高清原图制作页图。复用[更新工具的共享转换函数](../../../image_conversion.py) `convert_image_files_to_webp`。当前规则为超宽时以 Lanczos 等比缩到 1920 像素、有损 WebP、quality=75、method=6；以项目当前源码为准。仅转换本次素材，在独立暂存目录处理。函数会跳过 WebP 输入：已符合规则的直接复用；需要纠正已有无损图时，从高清原图或其无损解码结果转换一次。稳定编号，保留用户已有的有效图名，链接写作 `../images/<文件名>.webp`。
- 完整收录时核对 `_data/data.xlsx` 的 `interview` 表头。以最终 `md_path` 查重；若用户重命名，结合旧路径、标题、刊期检查并更新原记录。按同类条目填写 `poster`（优先已有对应封面）、`date`（核实的实际发售日，Excel 日期）、`interviewee`、`title`、`md_path`（`mc/<最终文件名>.md`）、`if_translated`（待译稿为 `no`）。可用工作簿已有的刊物发售记录核对日期，不能从刊期或文件名前缀推算具体日期。保留其他行、工作表、样式和公式。
- 写回时保留目标文件权限。Windows 下用临时文件替换工作簿或页图后，检查目标仍有与同目录同类文件一致的继承访问权限。若临时目录的限制跟随文件移入，只修复本次受影响文件。

## 交付前核对

按来源页逐一回看原文、问答轮次、页图对应位置和封面末置。检查原文标签成对、标题与占位规则、所有图片能从访谈页面路径解析并解码、发布图使用项目压缩格式。重新读取工作簿，确认唯一目标记录、封面与 Markdown 路径有效，更新工具的分页扫描能识别 `interview`。报告成稿路径、页图、登记结果及确有的疑点。全站构建与发布按用户另行要求执行。
