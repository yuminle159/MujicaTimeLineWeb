# 网页访谈更新

适用项目：唯鸡百科（当前仓库 `F:/mujicatimelineweb`）。先确认当前仓库，使用仓库相对路径；不要假定转换工具中写死的旧盘符仍有效。

## 默认完整流程

用户要求新增或更新网页访谈时，默认连续完成：网页／多页 HTML 提取 → Markdown 原文整理与图片转换 → 全文中文翻译 → 中文排版与逐段校对 → 同步工作簿。不要在生成 `（中文）` 占位稿后结束，也不需要另等一次翻译指令。

- 开始前完整读取仓库内的 [md文件翻译规则.md](../../../_data/_docs/md文件翻译规则.md)。它是中文翻译质量、专名、颜色与排版的统一依据，每次使用读取现行内容，不在 skill 中维护另一套副本。
- 用户明确要求仅整理原文、暂不翻译、仅翻译已有 Markdown、仅修正指定内容或仅写入工作簿时，按指定范围执行，不扩大为整套流程。未要求重译时保留已有人工校对译文；补页时翻译新增内容并核对上下文。
- 整理阶段先核对来源完整性、建立分块、翻译新建的大标题和小节标题、填写元信息及整理图注。新建图注中的说明文字在此阶段译成中文，按规范保留人名。进入正文翻译前保存整理后的基线，用于核对受保护内容；已有 Markdown 则以修改前版本为基线。
- 正文翻译阶段遵守规则中的受保护范围：不改原文块、已确定的标题、元信息、现有斜体图注、图片位置与链接。若任务明确要求补页或修正这些内容，先完成相应整理，再核对本次有意修改与其余受保护内容。
- 默认流程的成品是可直接刊登的中日文对照 Markdown、有效 WebP 图片及对应工作簿记录。存在缺页或未译内容时如实报告，不将部分完成标为全文翻译完成。构建和发布不属于默认流程。

## 读取与范围

- 先检查用户当前修改、目标 Markdown、图片、`_data/data.xlsx` 的 `interview` 表及其表头。保留用户已删除的宣发内容，不从旧 HTML 重新补回。
- 整理原文结构时，用 `if_translated=no` 确认未翻译示例，优先对照 `_data/mc/261022梅茜访谈.md`、`250728弄李访谈.md`、`20250130realsound渡濑结月访谈.md`。这些占位稿只供结构参考；中文风格参考按翻译规则选择已译的完整中日文问答，不使用其中明确排除的 `261109Billboard-Diggy-MO前篇.md`。
- 检查 HTML 的分页链接和用户提供目录内的全部分页面，按第 1、2、3 页顺序合并。SingleFile 的图片可直接从 data URI 解码。处理嵌套或不规范的 p 标签时避免丢失后半页正文或改变图片顺序。
- 保留导语、采访/摄影署名、小节标题、完整问答和正文照片。排除正文外的发行信息、商品版本/价格/曲目表、购买链接、广告、关联推荐、网站导航和分页提示。问答中谈论专辑、电影或未来演出仍是正文，不能当成宣发删掉。
- 本地文件不完整时如实说明缺页；用户随后提供补页时合并，不继续保留过时的缺页说明。原文缺失不能自行编造。

- 影像／视频链接一概不保留：删除嵌入播放器、iframe、视频缩略图及对应的观看链接和独立视频说明，不将嵌入内容改写成 Markdown 视频链接。访谈正文中关于影像、MV 或演出的讨论仍须保留；文章出处链接和正文照片不受此规则影响。

## Markdown 格式

- 翻译标题时保留原文书名号和引号样式，如 `『Completeness』`、`「曲名」`，不要替换成 `《Completeness》` 或其他中文标点样式。

- 图片下方小字使用单星号斜体 `*图片说明*`，独立放在图片后、其后的 `[br]` 前，且放在 `[original]` 块外。参考 `_data/mc/20250328羊李对谈.md` 的图注。人物图注不当作下一段问答，不为纯图注新增 `（中文）` 占位块。
- 确认发布日期后直接填写日期，不在 Markdown 中添加日期依据的 HTML 注释或额外说明；日期无法确认时再告知用户。

- 文件为 `_data/mc/<用户指定名称>.md`，UTF-8 无 BOM。中文大标题下依次写 `**访谈时间**：YYYY/MM/DD`、`**访谈人**：姓名 x 姓名`、`**出处**：[访谈原地址](URL)`，然后 `[br]`。日期取原文发布日，不取保存日期。人物中文名对照工作簿的名字规范及现有档案。
- 默认按 `_data/_docs/md文件翻译规则.md` 完成全文翻译，保留日文原文及受保护字段；只有用户明确要求暂不翻译或仅整理原文时，才以占位稿交付。全文完成并核对后才将 `if_translated` 改为 `yes`。
- 未翻译正文以图片为主要分界，连续问答归在同一块，不按每句或每个问答拆块。每块前写 `（中文）` 占位，原文完整包在 `[original]` 与 `[/original]` 之间。
- 图片放在原文块外，两侧使用 `[br]`；下段重新写中文占位和原文块。不要让图片进入可折叠的原文块。
- 小节标题是独立分界：先关闭正文原文块，以 `---` 分隔，写中文 `##` 标题，再以单独的 `[original]` 块保留日文标题。正文另起 `（中文）` 占位块。标题已翻译不意味着正文翻译完成。
- 日文原文不加人物 `[cN]` 颜色标签或给每句问答另加粗；保留原文字词和段落。已翻译文档则参考对应已译示例，保留现有译文与颜色规则。

整理阶段的中间稿示例（默认流程须继续替换占位并完成中文排版）：

```markdown
（中文）

[original]

日文问题与回答，保持原有段落。

[/original]

[br]

![采访图片1](../images/文件名-01.webp)

[br]

（中文）

[original]

后续日文正文。

[/original]
```

## 图片

- 最终放在 `images/`，命名 `<Markdown文件名>-01.webp`、`-02.webp`……；按正文顺序编号，Markdown 使用 `../images/` 路径。封面也应选用此次访谈的相关照片。
- 必须真实转换为 WebP，不是只改后缀。用户已转换时直接校验并更新引用，避免再次有损压缩。
- 使用项目自带 `to_webp.py` 的 `optimize_and_convert_to_webp(src_dir, max_width=1920, quality=75)`。先读取脚本确认接口；把本次待转换图片放入独立临时目录，导入函数并传入该目录，转换后将结果放入 `images/`。不要直接执行脚本 main 中硬编码的旧路径，也不要对整个 images 目录重压缩。
- 保留用户已有的编号与删图结果。清理只针对本次明确产生的临时材料，不删除无关资源。

## 中文翻译与排版

按翻译规则的执行顺序完成，不用格式检查替代翻译校对：

1. 通读合并后的全文及适合的已译参考，确认人物、指代、时间与术语；跨图片和小节结合上下文理解。
2. 将每个待译正文块的完整中文放在对应原文块上方，替换 `（中文）`；已在整理阶段译好的独立标题块不重复添加译文。覆盖导语、署名、所有问答和末尾段落，不摘要、不增写解释，保留说话人的口吻与原文的犹疑和表达强度。
3. 单独连读中文并润色，再逐段对照日文核对事实、遗漏、增译、否定、因果和说话人归属。已有人工校对内容不无故重写。
4. 中文确定后应用规则中的专名、问答间 `[br]`、加粗和 `[cN]` 标签。提问整段加粗且不加人物／乐队颜色；回答人与正文人物按语义标记；歌名保留原文，区分同名歌曲与乐队。完整映射与优先级以规则文件为准，不对全文做盲目替换。
5. 与翻译前基线对比，确认原文文本（含标点、空行、格式）及其他受保护内容保持不变。核对原文块、颜色和加粗闭合，无占位残留、重复间隔、嵌套颜色或提问误着色。

## 写回工作簿

- 默认完整流程在翻译与校对完成后同步 `_data/data.xlsx` 的 `interview` 表，用 `md_path` 定位并避免重复。只改目标行，保留其他工作表、现有数据、公式与样式；不要重建整本工作簿。仅翻译已有 Markdown 等限定任务不自动扩大到工作簿修改。
- 实际表头为准，目前字段：`poster`、`date`、`interviewee`、`title`、`md_path`、`if_translated`。
- `poster`：`../images/<相关封面>.webp`；`date`：Excel 日期；`interviewee`：规范中文名，用 ` x ` 分隔；`title`：简短展示名，格式 `YYYY/MM/DD-来源-访谈人`，例如 `2025/04/24-Billboard JAPAN-冈田梦以 x 米泽茜 x 高尾奏音`；不要填写文章全文标题；`md_path`：`mc/<文件名>.md`；未译正文 `if_translated=no`，完成全文翻译才设为 `yes`。
- 仅要求写入工作簿时不自动生成全站或部署。用户要求更新生成网页时，再检查项目生成入口并执行相应构建；发布遵循用户授权。

## 完成检查

确认页数和问答完整、宣发和分页导航已排除；默认成品的全部待译块均有中文且无 `（中文）` 占位，语言质量、内容完整性和标记结构分别通过校对；原文及受保护内容已与基线作内容对比；图片与图注在原文块外，每个图片引用实际存在且解码格式为 WebP；需要同步的工作簿仅有一个对应 md_path，封面有效。仅全文翻译与校对完成且无缺页时标记 `if_translated=yes`，仅整理、部分翻译或缺页时为 `no`。简要报告 Markdown、翻译与排版、图片、工作簿结果，以及确实存在的缺页或实质疑点。
